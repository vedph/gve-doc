# Editor User Experience

Once you land on the editor's homepage, you need to login with your account:

1. click the login button at the top right corner.
2. enter your credentials and login.

>If you are self-hosting the editor locally, the default credentials are username=`zeus` and password=`P4ss-W0rd!`.

Once logged in, new menu items will appear.

## Menus

- `Items`: the list of items. These belong to any of these types: snapshot, epigram, carrier, collection.
- `Search`: the search page for items.
- `Stats`: a page with a summary of the past edits over time, providing an overview of editing activity.
- `User`: user page. This is not effectively used in the GVE scenario.
- `Admin`: if the user is admin, this menu allows to manage user accounts, hints, flags, thesauri, facets and settings.

The button at the top-right corner with a moon or a sun icon allows you to toggle between dark and light themes.
